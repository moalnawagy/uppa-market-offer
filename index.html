Project scope

This offer covers the complete platform described in the Uppa Market Platform Technical Specifications, version 1.0. The scope below follows that document layer by layer.

Uppa Market is a multi-vendor e-commerce marketplace that connects Egyptian merchants with consumers in Gulf markets, with shipping built in. It starts in Saudi Arabia and expands to the wider GCC, then Europe and the USA. The experience is inspired by Shein, Temu and Trendyol, with a focus on Egyptian products.

Technology

We keep the architecture, data layer and cloud setup from the specification. Two choices change: the mobile framework and the backend framework.

What changes from the specification

Customer mobile app

React Native Flutter

One codebase produces the iOS and Android apps, with the same screens and behavior on both. Flutter switches cleanly between Arabic (RTL) and English (LTR) layouts, which the bilingual experience depends on.

Backend

Node.js or Django Spring Boot

A mature, enterprise-grade framework with built-in security and reliable transaction handling, which suits the order, payment and vendor payout logic of a marketplace. It scales out on AWS as traffic grows.

The customer website, vendor dashboard and admin backend keep the web technologies proposed in the specification.

Quality and compliance

A dedicated QC tester works from the first phase, so problems are found while the work is still fresh and no phase reaches you untested.

  1. Plan

    Test plan and test cases are written from the specification during Phase 1.

  2. Test each build

    Functional and API tests run as features land, on iOS, Android and the main browsers.

  3. Regress

    Regression runs before every milestone hand-over to catch anything that broke.

  4. Sign off

    QC sign-off is required before a phase is presented for your acceptance.
